🤖 jaiid Extension Test Page

Purpose: This page contains various images to test the jaiid (Just AI image descriptions) Chrome extension's functionality.

📘 Testing Instructions:
  1. Load the jaiid extension in Chrome (see README.md)
  2. Click the extension icon in the toolbar
  3. Look for info buttons () on eligible images below
  4. Click a button to generate AI alt text
  5. Verify accessibility with keyboard navigation (Tab, Enter, Esc)

✅ Testing Checklist

Verify the following:

  • Info buttons appear only on eligible images
  • Each button has a unique accessible label
  • Clicking a button opens a popover dialog
  • Popover shows loading indicator initially
  • Alt text is generated and displayed
  • Escape key closes the popover
  • Clicking the button again closes the popover
  • Screen readers announce the alt text
  • Tab navigation works correctly
